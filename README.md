# MY-MONEY-Logger

농협 저축 잔액과 입출금, 다음 달에 다시 채울 금액을 관리하는 개인용 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages에 `main / root`를 게시하면 됩니다. 서버, API 키, 계좌 연결은 필요하지 않습니다. GitHub Pages 배포는 저장소 Settings → Pages → Deploy from a branch → `main` / `(root)`에서 설정하세요. 이 저장소에 코드를 업로드하는 것만으로 공개 URL 배포가 자동 완료되는 것은 아닙니다.

## 데이터와 보안

실제 은행 거래를 수행하거나 농협 계좌 잔액을 실시간 조회하지 않습니다. 입력한 기록으로 계산한 앱 잔액입니다. 모든 기록은 브라우저의 로컬 저장소에 Web Crypto AES-GCM으로 암호화해 보관하고, 입력한 6자리 PIN에서 PBKDF2로 키를 생성합니다. 비밀번호 원문은 보관하지 않지만 6자리 PIN은 추측에 취약할 수 있으므로 은행 수준의 보안을 보장하지 않습니다. 공유 기기 사용을 피하고 암호화된 백업 파일을 안전하게 관리하세요. 브라우저 데이터를 삭제하거나 다른 기기에서 접속하면 자동으로 동기화되지 않습니다.

## 주요 기능

- 초기 잔액 등록 및 6자리 비밀번호 설정/변경, 화면 키패드
- 홈: 기록된 잔액, 미상환 금액, 다음 달 목표, 입금/출금
- 일반 입출금과 다시 채울 돈(출금)/부분 상환(입금) 구분
- 거래 확인 → 비밀번호 인증 → 암호화 저장 → 완료 내역
- 최신순 기록, 날짜/금액 검색, 상세, 정정, 취소 및 변경 이력
- 월별 통계, 기록을 생성하지 않는 직접 잔액 조정
- 암호화된 JSON 파일 백업/복원 및 전체 초기화

날짜와 금액은 실제 기기의 현지 시간 및 원화 정수 기준입니다. 일부 브라우저의 사생활 보호 모드에서는 로컬 데이터 보존이 제한될 수 있습니다.
